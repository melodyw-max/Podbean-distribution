01页面概述

Stats 页面（Statistics，数据页面）是播客数据统计与分析看板。主菜单 Statistics 下不再设置子菜单，页面以「一个页面 + 5 个 Tab」的方式组织，5 个 Tab 分别为：

  • Overview（总览）：以图表和指标卡片的形式，快速查看整体表现与趋势。
  • Performance（单集表现）：按单集维度深入分析收听表现。
  • Trends（下载趋势）：以时间序列图表展示下载量随时间的变化趋势。
  • Engagement（互动）：查看听众在 Podbean 内的互动（收听行为）。
  • Report（报告）：以表格和明细数据的形式，查看底层原始数据与可下载的报告。

页面中，Engagement（互动）与 Podbean App User Retention（用户留存）等视图仅展示 Podbean 的数据；其余视图展示各平台的汇总数据。

此外，页面中的各列表在数据达到一定数量时会自动分页；各列表当前不支持排序交互。

不同套餐（Free / Business / Network 等）可用的功能不同，本文在相应位置标注了套餐差异。

03Overview（总览）

总览 Tab 是进入 Stats 页面后的默认视图，用于以可视化的方式快速了解播客的整体数据表现。左上方提供时间选择器，用于控制整页数据的时间范围。

上个月（如 Dec 2024）上个月

Custom 时间选择器：

  • Network 套餐及以上：自定义范围可选 5 年内。
  • Network 套餐以下：自定义范围可选 2 年内。
  • Custom 的图表展示时间维度始终为 month。

All Time 图表时间维度：

  • Network 套餐及以上，数据超过 5 年：按 year 展示。
  • Network 套餐以下，数据超过 2 年：按 year 展示。
  • 未超过上述年限：一律按 month 展示。

3.2 指标（KPI）定义

指标说明（页面原文）含义
DownloadsCounts every time the episode file is accessed — including downloads and online streaming.每次访问单集文件都计一次，包含下载与在线流式播放。
ListenersThe total number of daily listeners, summed across all days.每日听众数在所有天数上的总和。
New FollowersThe number of net new followers per day, summed across all days.每日净新增关注者数在所有天数上的总和。
InteractionThe interaction is calculated as the number of likes plus the number of comments.互动 = 点赞数 + 评论数。
  • Interaction 数值计算：Interaction = Likes（点赞数）+ Comments（评论数）。

3.3 数据范围与限制

与 Dashboard 页面的一致性：

  • Dashboard 的 Downloads Trending 板块展示包含今天在内的 14 天数据。
  • Dashboard 与 Overview 的 Last 7 / Last 30 / All Time 数据保持一致。

Downloads 图表起始时间：

  • Overview 页面的 Downloads 图表从 2015 年开始记录，因此可能出现「图表数据相加小于 Downloads 总数」的情况。

Listener 板块（仅 Last 24 Months）：

  • 若时间选择器完全超出 Last 24 Months，Listener 板块展示：There is no data for this view. Statistics are available for up to 24 months.
  • 若时间选择器一部分覆盖 Last 24 Months，Listener 图表展示已有数据，没有的数据展示为 0。

New Followers 与 Interaction 板块（自 Jan 01, 2023 起）：

  • New Followers 和 Interaction 只能提供 Jan 01, 2023 之后的数据。
  • 若时间选择器完全在 Jan 01, 2023 之前，Follower 和 Interaction 板块展示：There is no data for this view. Statistics are collected since Jan 01, 2023.
  • 若时间选择器一部分覆盖 Jan 01, 2023 之后，图表展示已有数据，没有的数据展示为 0。

GEO / Platforms / Sources / Most Active Times 板块（仅 24 个月）：

  • 这四个板块只有 24 个月的数据，时间范围超出即展示：There is no data for this view. Statistics are available for up to 24 months.
  • 这四个板块无数据时，展示 No data found.

3.4 各数据板块逻辑

Most Active Times（最活跃时段，GMT）：

  • 某个小时区间的数字（四舍五入）= round（[每周 x 该小时区间内的 downloads 总数] ÷ [周 x 出现的次数]）。
  • 某个星期区间的数值 = 图表里该星期 24 个小时数字之和。（由于小时数据是四舍五入，因此可能出现「星期数据大于上方 downloads」的情况。）
  • 当时间选择器包含今天时，会将当日实时数据一起计算。
  • 当所有 hours 的柱子都在大于 0 且小于 0.5 之间时，显示 Not enough data。

Podbean App User Retention（用户留存）：

  • 时间选择器为 Today / Last 7 Days / Last 30 Days 时，展示 last 7 weeks 数据。
  • 时间选择器为除以上三个时间段外的选项时，展示 last 7 months 数据。
  • 该板块展示逻辑不随具体时间范围变化（仅按上述规则切换周/月）。

Podcast Trends 板块（按 channel 类型显示）：

  • public channel：展示 New Followers。
    • 展示 follower / like / comments 的数字，不体现 unfollow、unlike、uncomments 的行为（若行为不在同一天）。
    • 若 follow 和 unfollow 在同一天，则会相互抵消。
    • 若不在同一天（例如一月 follow 了 10 个、unfollow 了 5 个），follow 数字仍显示 10。
  • private channel：展示 Playtime (mins)。
    • Playtime 每天 3:30（UTC）更新。
    • Playtime 的 mins 是取整（不是四舍五入）：playtime = 播放的所有秒数 ÷ 60。

Podcast Trends 板块环比数据：

  • 若上一周期无数据、该周期有数据，则该周期环比百分比展示为 100%。
  • 若上一周期有数据、该周期无数据，则该周期环比百分比展示为 -100%。
  • 若上一周期和该周期数据一致，则环比百分比展示为 +0%。

Latest Episodes / Top Episodes 板块：

  • 该板块为左右切换的两个 Tab：Latest Episodes（最新单集）与 Top Episodes（热门单集），两者各展示 5 个 episodes。
  • 发布时间按照 GMT 时区展示。（注：Episode List 页面的发布时间按用户账号设置的时区展示，因此两个页面的 episode 发布日期可能因时区不同而不同。）
  • Latest Episodes 的 Compare Performance 按钮：点击跳转至 Statistics 页面的 Performance Tab，选中该 5 个 episodes，时间默认选为 7 Days After Release。
  • Top Episodes 的 View More 按钮：点击跳转至 Statistics 页面的 Trends Tab。
  • 点击 episode title 跳转至 Statistics 页面的 Trends Tab，选中该 episode，时间选择器与 Overview 所选时间段保持一致。

3.5 Source 归因逻辑（自 2025-06-09 起应用）

  1. agent 为浏览器，且 Reference url（用户点击之前所在的网页地址）来自 Podbean domain：
    • 若为用户站点，则记录为 Podcast Website。
    • 若为 mcdn.podbean.com / media server（Podbean domain）：
      • 忽略 Reference url，只按 agent 记录为对应的浏览器 ——（2025-09-24 新增的规则）
      • mcdn.podbean.com 举例：media manager 中的 file url。
      • media server 举例：如 s301.podbean.com 的一次访问，显示 ref url 也是 s301.podbean.com，则忽略 ref url，只用 agent 判断。
    • 若路径为 player-v2，则记录为 Podbean Embed Player。（player-v2 是 embed player 的 url）
    • 其他一律记录为 Podbean App（包含 Podbean App、Podbean Pro App 的播放）。
  2. agent 为浏览器，但 Reference url 不是 Podbean domain：
    • Apple、Spotify、Podmatch 网站网页版本播放应自动归为相应的 platform。
    • 提交到非 Apple、Spotify、Podmatch 的其他第三方网页播放，自动归为对应的浏览器。
  3. 其他 source 根据通用的 Parse Agent 归因。

3.6 页面控件与导出

  • 第一个表格（列表）为左右切换的 Tab（Downloads / Listeners / New Followers / Interaction），切换到不同 Tab 时下方表格显示对应指标数据；表头为 Title、Released (GMT) 及对应的指标列；该表格提供 Export CSV 按钮。
  • 第二个表格提供 Latest Episodes / Top Episodes 的左右 Tab（各展示 5 个 episodes），用于切换「最新单集 / 热门单集」；表头为 Title、Released (GMT)、Downloads。
  • Where Your Audience Comes From 标题下方提供地区选项：World、U.S.、Canada、Australia、UK、Sweden、Germany；该板块左下角有 Export CSV 按钮。
  • Platforms 与 Sources 左下角都有 Export CSV 按钮。
  • Free 用户的 Dashboard 页面不展示 Episode Performance 板块。

04Performance（单集表现）

展示播客单集层面的收听表现。

主要功能：

  • 以长滚动布局展示整体概览与分集表现明细。
  • 表格上方提供 Compare（对比基准） 选择器，用于选择对比基准（与最近 N 集的平均下载量对比）。
  • 右侧提供 Days After Release（发布后 N 天） 选择器，用于按「发布后经过的天数」来统计表现。
  • 左下角提供 Export CSV 按钮（带下拉箭头），选项：Export selected episodes、Export all episodes (up to 500)。

Compare（对比基准）下拉选项：

选项说明
Compare to Average Downloads of Last 10 Episodes与最近 10 集的平均下载量对比
Compare to Average Downloads of Last 50 Episodes与最近 50 集的平均下载量对比
Compare to Average Downloads of All Episodes (Up to 500)与全部单集（最多 500 集）的平均下载量对比

Days After Release（发布后 N 天）下拉选项：

选项说明
7 Days After Release发布后 7 天
14 Days After Release发布后 14 天
30 Days After Release发布后 30 天
60 Days After Release发布后 60 天

表格列名：

列名说明
Episode Title单集标题
Released (GMT)发布时间（GMT）
7 Days After Release发布后 7 天（该列随 Days After Release 选择器的值变化，如 14 / 30 / 60 Days After Release）
Compare to Average对比基准列，副标题为 "Compared to the 'Average Downloads' option you have selected."（与你所选的平均下载量基准对比）
Date Range日期范围
Actions操作

计算逻辑：

  • 图表中 Average 的数据每天 UTC 2 点计算，当天计算前一天的数据。
  • 由于发布时间不够，episode download 和 average 的曲线都存在断点的情况。
  • 非 publish 状态的 episode 不会出现在页面下方的 episode 列表里。
  • 页面根据 episode 查数据，查询最新发布时间之后的数据。

Compare to Average 的特殊计算显示：

  • Episode download = 0 且 average = 0 时，Compare to Average 用 "-"。
  • Episode download = 0、average 有数值时，compare 的百分比显示为 -100%。
  • Episode download 有数值、average 没有（断点）时，compare 的百分比也展示为 "-"。
Free 用户不提供 Performance 数据。

05Trends（下载趋势）

以图表形式展示下载量随时间的变化趋势。

主要功能：

  • 左侧提供 Selected Episodes（选择单集）：点击打开 Select Episodes 弹窗，弹窗上方有 Search Episodes 搜索框，下方出现 All Episodes 及单个 episode 标题（从新到老排列）供选择（列表不含日期、不支持全选）。
  • 右侧提供 Time（时间范围） 选择器。
  • 下方提供 View by Episodes / View by Date 的左右 Tab，用于切换按单集或按日期查看趋势；两个 Tab 视图左下角都有导出按钮。

Time（时间范围）下拉选项：

  • 付费用户：Today / Last 7 Days / Last 30 Days / 本月 / 上个月 / 上上个月 / Custom (within 24 months) / All Time
    • Last 7 Days / Last 30 Days 不包含今天。
    • All Time：从 blog 创建时间开始。
  • 免费用户：不展示 Custom (within 24 months) / All Time，其他选项可展示。

Download 板块的环比：

  • Time A-Time B VS Time C-Time D：Time C 最早提供到两年前，超过两年不提供环比信息。
  • 三种为 0 的情况：
    • 环比前后数据均 = 0，百分比为 +0%。
    • 当前有数据、环比时间数据 = 0，百分比为 +100%。
    • 当前数据 = 0、环比时间有数据，百分比为 -100%。

Avg. Downloads 的计算：

  • 不足整月时，取大值计算。
  • 所选范围内如果有没有 download 的情况，不会扣除，依旧算进除数里。

柱形图时间显示规则：

  • 用户选择的时间在 3 个月内：按照天展示数据。
  • 超过 3 个月且在 24 个月内：按照月展示数据。
  • 超过 24 个月：按照年展示数据。

柱形图数据逻辑：

  • All episode > all time：从 blog 创建时间显示和计算数据。
  • 单个 episode、all time：从 file 发布时间显示和计算数据。
  • 其他时间选择：若 time range 内 episode 还未发布，则数据为 0，时间轴仍按照时间选择器的 range 来。

All episode > View by episode：

  • 根据 file 查数据；多个 episode 用了同一个 file 则展示最新的 episode。
Free 用户可查看 All episode 数据，不可查看单个 episode 数据。

06Engagement（互动）

用于查看听众在 Podbean 平台内的互动（收听行为）表现的视图。

主要功能：

  • 左侧提供 Select Episodes（选择单集）：点击打开 Select Episodes 弹窗，弹窗上方有 Search Episodes 搜索框，下方按「从新到老」排列单个 episode 的标题供选择（列表不含日期、不支持全选）。
    • 搜索框只可搜索有 engagement 数据的 episode。
  • 右侧提供 Time（时间范围） 选择器。
  • 左下角提供 Export CSV > 文字链接，点击跳转到 Report 的 Engagement Raw Data。

Time（时间范围）下拉选项：

选项说明
All time全部时间
This month本月
Last month上月

图表时间间隔规则：

  • General users 和 Network users：时间间隔为 10 秒。
  • Business user：时间间隔为 1 秒。

Session 展示规则：

  • Private podcast：列出所有用户的「收听行为」，用户 email 信息被遮挡。
  • Business publish podcast：列出 50 个用户的「收听行为」，用户 email 信息格式为 Listener- [随机字符]。
  • 其他付费 plan：列出 10 个用户的「收听行为」，用户 email 信息格式为 Listener- [随机字符]。

用户信息包含：

  • 时间
  • 地址
  • 用户 email
  • platform：via embed player / via Podbean app (Android) / via Podbean app (iOS) / via podcast website / via Podbean Pro app (Android) / via Podbean Pro app (iOS) / via your white label app (Android) / via your white label app (iOS)

Engaged Users 逻辑：

  • private：engaged users 数量按照 session 比例 >= 40% 计为 1 个 engaged listener。
  • public：engaged listeners 不按上面的 session 计算，计算方法为：同一个 episode、1 个 listener、一个月算一个 session；总时长 >= 40% 算一个 engaged listener。在 10/50 sessions 里同一个 listener 的新 session 会覆盖老的 session。因此上面的 engaged listeners 数字 >= 下面的 engaged session 数字。

Listeners on Podbean 逻辑：

  • private：数据永久保存，Listeners on Podbean = Sessions 数量。
  • public podcast：
    • ≤ 50/10 session 时，Listeners on Podbean = Sessions 数量。
    • > 50/10 sessions 时，Listeners on Podbean > Sessions 数量。

其他规则：

  • session 百分比的计算四舍五入（所有数据的计算都是四舍五入）。
  • Public podcast 未保留上线前的数据，数据从上线后（2025.04.08）开始收集。
  • 执行时间：Session 数据与 Listeners on Podbean 数量同步更新，平均每 10 分钟执行一次；Engaged Listener 每小时的第 17 分执行。
Free 用户不提供 engagement 数据。

07Report（报告）

报告 Tab 用于下载播客数据报告。页面顶部提供报告类型下拉框，下方按月列出报告，每份报告右侧都有下载按钮。

7.1 报告类型下拉框

Report 页面顶部有一个下拉框，用于选择要查看/下载的报告类型，包含四个选项：

  • Raw Data（原始数据）：未经聚合的底层明细数据。
  • Engagement Raw Data（互动原始数据）：互动相关的明细数据。
  • Engagement Summary（互动摘要）：互动数据的聚合摘要。
  • Podcast Performance Snapshot（播客表现快照）：播客表现的一页式快照。

不同报告类型对应不同的时间选择：

报告类型时间选择器其他
Raw Data以年为单位另有 Add Filter 按钮
Engagement Raw Data以年为单位—
Engagement Summary仅 All time—
Podcast Performance Snapshot以年为单位仅 Network 套餐及以上（Network plan and above）用户可用

7.2 Raw Data（原始数据）

  • 右侧提供时间选择器（以年为单位）。
  • 时间选择器旁提供 Add Filter 按钮，点击打开 Download Report Filter 弹窗，内容如下：
  • 标题：Download Report Filter
  • 说明文字：Select the report information you wish to download.
  • 可勾选字段：Episode Title、User、User Agent、State、Country、Play Time (When)、Episode Author
  • 备注：The selected filters will be applied to the future generated reports and the raw data report downloaded via API.

7.3 Engagement Raw Data（互动原始数据）

  • 右侧提供时间选择器（以年为单位）。

7.4 Engagement Summary（互动摘要）

  • 右侧时间选择器只有一个选项：All time。

7.5 Podcast Performance Snapshot（播客表现快照）

  • 该报告类型默认不展示，需要在 bo company 中 Enable analytic report 后，才会在 Report 页面出现。
  • 该报告类型仅对 Network 套餐及以上（Network plan and above） 用户开放。
  • 以「快照」形式展示播客表现在某一时间点或时间段内的整体情况，适合用于定期汇报、周报/月报或对外分享。
  • 右侧提供时间选择器（以年为单位）。

7.6 下载报告

  • 选择报告类型与时间后，下方按月列出报告，每个报告月份右侧都有一个 Download 按钮，点击即可下载对应报告。
  • 下载的文件格式为 CSV。
  • 各报告类型下方的报告列表表头一致，仅两列：Date Range（日期范围）与 Actions（操作，含 Download 按钮）。
